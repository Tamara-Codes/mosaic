## 🔄 Routing Architecture

### Frontend Routes (`frontend/src/main.tsx`)

```
/                          → LandingPage
/login                     → LoginPage
/sign-in                   → LoginPage
/sign-up                   → LoginPage
/dashboard/*               → App (AdminDashboard - protected)
/:restaurantSlug           → PublicMenuRedirect (catch-all)
```

**How it works:**
1. Landing page & auth routes are public
2. Dashboard is protected (requires Clerk authentication)
3. Catch-all `/:restaurantSlug` redirects to the public menu

### Restaurant Frontend Routes (`restaurant/src/main.tsx`)

```
/:restaurantSlug           → MenuPage (clean URL)
/menu/:restaurantSlug      → MenuPage (legacy, for backward compatibility)
*                          → 404 Not Found
```

**How it works:**
1. Supports both clean and legacy URLs
2. MenuPage component handles both route formats
3. Displays restaurant menu with language selection

### Backend Routes

```
/api/...                   → FastAPI endpoints
/api/qr-code              → Returns QR code pointing to /:restaurantSlug
/api/menu/{slug}          → Public menu data (for backward compatibility)
```

## 📋 Request Flow

### When customer scans QR code:

```
1. QR code contains: https://ferros.menu/pizza-place

2. Browser navigates to https://ferros.menu/pizza-place

3. Frontend router catches "pizza-place" as :restaurantSlug

4. PublicMenuRedirect component runs:
   - Extracts restaurantSlug from URL params
   - Redirects to restaurant subdomain/app with slug
   
5. Restaurant app loads MenuPage component:
   - Fetches restaurant data from API using slug
   - Displays menu in selected language
   - User can change language with selector
```

### When manager logs in:

```
1. Manager clicks "Login" on landing page

2. Clerk authentication modal appears

3. After login, redirects to /dashboard

4. Dashboard is rendered (AdminDashboard component)

5. Manager can create/edit menus, upload images, generate QR codes
```

## 🔐 Security

### Protected Routes

Dashboard routes require Clerk authentication:
- `/dashboard` → Requires logged-in user
- `/dashboard/*` → All sub-routes protected

### Public Routes

Anyone can access:
- `/` → Landing page
- `/login`, `/sign-in`, `/sign-up` → Auth pages
- `/:restaurantSlug` → Public menu (no auth needed)
